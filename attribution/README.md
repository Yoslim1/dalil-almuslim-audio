# النسبة والتراخيص

يخصص لكل قارئ ملف Markdown يحمل الاسم نفسه لمعرفه. يجب أن يتضمن اسم القارئ، صاحب الحقوق أو المصدر، رابط الملف الأصلي، نص أو رابط الترخيص، وتاريخ التحقق، وأي تعديل تقني أجري على الملف.

لا يكفي رابط استماع عام أو اسم قارئ. التسجيل الصوتي عمل له حقوق مستقلة حتى عندما يكون نص القرآن متاحًا.
