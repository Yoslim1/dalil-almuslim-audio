# مكتبة دليل المسلم للتلاوات

هذا المستودع مخصص لفهارس التلاوات والملفات الصوتية الاختيارية لتطبيق **دليل المسلم**. لا تُضمّن ملفات الصوت داخل APK، ولا يُنشر قارئ قبل تحقق آلي من بنية الفهرس وتوثيق مصدره وترخيصه.

## بنية المستودع

| المسار | الغرض |
|---|---|
| `library-manifest.json` | قائمة القراء التي يمكن للتطبيق اكتشافها |
| `reciters/<id>/manifest.json` | فهرس السور والتوقيتات الآية-بآية والبصمات |
| `attribution/` | نسب المصادر والتراخيص القابلة للمراجعة |
| `scripts/validate-manifests.mjs` | تحقق بنيوي إلزامي قبل النشر |

تستضاف ملفات MP3 الكبيرة في GitHub Releases، لا داخل Git history. يكون المستودع خاصًا في مرحلة التدقيق. لا يمكن لتطبيق عام تنزيل ملفات منه ما دام خاصًا؛ لا يجري تحويله إلى عام قبل اكتمال حقوق كل مكتبة صوتية والموافقة على النشر.

يوجد في `candidates/` أي مصدر مرشح تم التحقق من رخصته المبدئية لكنه لا يحقق بعد معيار التوقيت الآية-بآية. هذه الملفات ليست جزءًا من `library-manifest.json` ولا يراها التطبيق.

## قواعد القبول

لا يُقبل أي قارئ بالحالة `published` إلا إذا كان ملفه يثبت الترخيص والنسبة، ويغطي كل آيات السورة بترتيب زمني كامل، ويحمل بصمة SHA-256 لكل ملف صوتي. التفاصيل الفنية موجودة في مشروع التطبيق في `docs/audio-library-architecture.md`.
